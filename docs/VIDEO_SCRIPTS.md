## Production Notes

### Tools (Free Tier)
- **Script writing:** ChatGPT (you're using it)
- **Storyboard:** Canva (free) or Google Slides
- **Animation:** 
  - D-ID (free trial for avatar)
  - Canva animations (free tier)
  - LottieFiles (free animations)
- **Voiceover:** ElevenLabs (free tier)
- **Video editing:** CapCut (free) or OpenShot

### Batch Approach for 0 Budget
1. Generate 1-second clips using free tools
2. Download each clip
3. Merge using CapCut/OpenShot
4. Add voiceover (record yourself or use free TTS)
5. Add background music (YouTube Audio Library - free)

### Alternative: Screen Recording Demo
If animation is too complex:
1. Record screen using OBS (free)
2. Walk through actual app
3. Add voiceover
4. Add text overlays
5. Export and upload

### Distribution
- YouTube (free hosting)
- Loom (free for short videos)
- Google Drive (share with investors)
- Embed on website
